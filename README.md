# 🏰 Shadow of the Ancient Keep - Adventure Engine

Ένας **Data-Driven Game Engine** σε Java, σχεδιασμένος για την υλοποίηση Text-Based Adventure games. Το project αναπτύσσεται στο πλαίσιο του μαθήματος "Μεθοδολογία Προγραμματισμού".

## 🚀 Στόχος του Project
Η δημιουργία μιας αρχιτεκτονικής όπου η λογική του παιχνιδιού (Java) είναι πλήρως αποκομμένη από το περιεχόμενο (JSON). Αυτό επιτρέπει την αλλαγή ολόκληρου του σεναρίου χωρίς τροποποίηση του πηγαίου κώδικα.

## 🛠️ Τεχνολογίες
* **Γλώσσα:** Java
* **Βιβλιοθήκη Parsing:** Jackson Databind (για το χειρισμό JSON αρχείων)
* **Data Format:** JSON

## 🎮 Λειτουργίες (Week 3 Status)
* **Dynamic World Loading:** Αυτόματη φόρτωση δωματίων, εξόδων και αντικειμένων.
* **Command Parser:** Αναγνώριση εντολών φυσικής γλώσσας (`go`, `look`, `inventory`).
* **Game Loop:** Συνεχής ροή παιχνιδιού με χρήση Scanner.
* **Error Handling:** Διαχείριση λανθασμένων εντολών και άκυρων κινήσεων.

## 📂 Δομή Αρχείων
* `src/Main.java`: Η είσοδος της εφαρμογής και το βασικό Loop.
* `src/CommandParser.java`: Η λογική ανάλυσης των εντολών του παίκτη.
* `src/GameLoader.java`: Ο μηχανισμός φόρτωσης του κόσμου από το JSON.
* `src/main/resources/world.json`: Το αρχείο δεδομένων που περιέχει το σενάριο.
